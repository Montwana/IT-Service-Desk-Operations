# Helpdesk Overview

## Project Background

Botabota Office Solutions is a simulated small business with employees across departments including Finance, Sales, HR, Administration, Operations and Marketing.

This project demonstrates how an IT support technician manages user-reported technical issues and service requests using Spiceworks Cloud Help Desk.

## Project Objectives

- Manage and track IT support tickets.
- Categorise and prioritise incidents.
- Document troubleshooting activities and resolutions.
- Practise professional communication with users.
- Maintain incident records and support documentation.

## Tools and Technologies

| Tool | Purpose |
|---|---|
| Spiceworks Cloud Help Desk | Ticket management and incident tracking |
| Microsoft 365 | Simulated application support scenarios |
| AnyDesk | Remote support learning scenarios |
| GitHub | Technical documentation and portfolio |

## Project Scope

The project covers common IT support scenarios, including:

- Microsoft 365 application issues.
- Printer and hardware problems.
- Network connectivity issues.
- Computer performance problems.
- User service requests.

## Simulation Disclaimer

This is a practical learning project. The company, employees, tickets, user responses and incident outcomes are simulated. The project does not represent support work performed for a real organisation.
