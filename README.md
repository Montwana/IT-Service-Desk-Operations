# 🖥️ IT Service Desk Operations

### A Practical IT Support and Helpdesk Project

[![Helpdesk](https://img.shields.io/badge/Project-IT%20Helpdesk-blue)]()
[![Platform](https://img.shields.io/badge/Platform-Spiceworks-orange)]()
[![Documentation](https://img.shields.io/badge/Documentation-GitHub-black)]()
[![Status](https://img.shields.io/badge/Status-Completed%20Core%20Scenarios-success)]()

A hands-on IT support simulation demonstrating how a service desk technician manages support tickets, investigates technical issues, documents resolutions and creates knowledge-base resources.

The project uses **Spiceworks Cloud Help Desk** to simulate a business IT support environment for a fictional company, **Botabota Office Solutions**.

---

## 🎯 Project Objectives

- Practise service desk ticket creation and management.
- Assess incidents based on impact and urgency.
- Apply structured troubleshooting methodologies.
- Document technical investigations and resolutions.
- Develop user support and incident communication skills.
- Create reusable knowledge-base documentation.

| Windows troubleshooting concepts | Network and printer support scenarios |

## 🎫 Simulated Support Incidents

The project includes three documented incident scenarios covering common workplace IT support issues.

| Incident | Issue | Technical Focus |
|---|---|---|
| INC001 | Outlook connectivity issue | Microsoft 365 and add-in troubleshooting |
| INC002 | Printer connectivity issue | Printer configuration and Print Spooler |
| INC003 | Network connectivity issue | IP configuration and DHCP |

### Key Outcomes

- Identified a simulated Outlook add-in conflict.
- Investigated an incorrect printer port configuration.
- Identified an incorrect network IP configuration.
- Documented corrective actions and verification steps.
- Recorded simulated user feedback and ticket outcomes.

This is a **simulated IT support project** created for practical learning and skills development. Botabota Office Solutions, its employees, support requests, user responses and incident outcomes are fictional. Troubleshooting results are documented as simulated scenarios and do not represent support work performed in a live business environment.
